## ⚙️ Customization Examples

### Monitor Different Symbols
Edit `config.json`:
```json
"symbols": [
  "BTC/USDT",
  "ETH/USDT",
  "SOL/USDT"
]
```

### Faster Monitoring (Scalper)
```json
"general": {
  "check_interval": 3    // Every 3 seconds
}
```

### Slower Monitoring (Swing Trader)
```json
"general": {
  "check_interval": 60   // Every 60 seconds
}
```

### Disable RSI Alerts
```json
"rsi": {
  "enabled": false       // Won't generate RSI alerts
}
```

### Turn Off Sounds
```json
"general": {
  "enable_sound": false  // Silent mode
}
```
