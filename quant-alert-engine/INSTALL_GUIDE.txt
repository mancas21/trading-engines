IMPORTANT STEPS

STEP 1: Install Python
───────────────────────
Go to: https://www.python.org/downloads/

Download: Python 3.10+ for Windows (64-bit)

Run installer:
  1. Click "Add Python to PATH" ✓ (IMPORTANT!)
  2. Click "Install Now"
  3. Wait for completion
  4. Close installer

Verify:
  1. Open Command Prompt
  2. Type: python --version
  3. Should show: Python 3.10.x or higher


STEP 2: Extract Files
──────────────────────
Extract all 7 files to a single folder, e.g.:
  C:\Users\YourName\quant-alert-engine\

Files MUST be in same folder:
  ✓ quant_alert_engine.py
  ✓ config.json
  ✓ setup_windows.bat
  ✓ run_engine.bat
  ✓ requirements.txt
  ✓ README.md
  ✓ QUICK_REFERENCE.txt


STEP 3: Run Setup
──────────────────
1. Right-click in folder → "Open Command Prompt here"
2. Or: Right-click → "Open PowerShell window here"
3. Type: setup_windows.bat
4. Press Enter
5. Wait for completion (2-5 minutes)

Output should show:
  [OK] Python is installed
  [OK] Virtual environment created
  [OK] All packages installed successfully
  [OK] Directory structure created
  SETUP COMPLETED SUCCESSFULLY!


STEP 4: Edit Configuration
───────────────────────────
1. Open config.json with Notepad (or VSCode)

Example AFTER (Bitcoin & Ethereum):
  "symbols": ["BTC/USDT", "ETH/USDT"],

Save file (Ctrl+S)

─────────────────────
1. Double-click: run_engine.bat
2. Console opens
3. See: "QUANT ALERT ENGINE v1.0 - Starting"
4. Alerts appear here + Windows notifications

COMMON ISSUES & FIXES

Issue: "Python is not recognized"
─────────────────────────────────
Solution:
  1. Reinstall Python from python.org
  2. Check "Add Python to PATH"
  3. Restart Command Prompt


Issue: "ModuleNotFoundError"
────────────────────────────
Solution:
  1. Open Command Prompt in folder
  2. Type: venv\Scripts\activate.bat
  3. Type: pip install -r requirements.txt


Issue: No alerts appearing
──────────────────────────
Solution:
  1. Check config.json - is symbol correct? (SOL/USDT not SOLUSDT)
  2. Enable indicators: "enabled": true
  3. Check quant_alert_engine.log for errors
  4. Try a major pair first: BTC/USDT or ETH/USDT


Issue: Windows notifications not showing
────────────────────────────────────────
Solution:
  1. Settings → System → Notifications
  2. Enable notifications
  3. Or disable in config: "enable_notifications": false


Issue: High CPU usage
─────────────────────
Solution:
  1. Increase check_interval to 30 seconds
  2. Reduce number of symbols
  3. Disable unused indicators
