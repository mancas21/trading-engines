## Common Customizations

### Change Symbols
Open `config.json`, find this section:
```json
"symbols": [
  "SOL/USDT",
  "XRP/USDT",
  "SUI/USDT"
]
```

Replace with your pairs (examples):
```json
"symbols": [
  "BTC/USDT",
  "ETH/USDT",
  "BNB/USDT"
]
```

### Change Check Speed
Default is 5 seconds. Edit in `config.json`:
```json
"general": {
  "check_interval": 5    // Change this number
}
```

Options:
- `3`: Fast (every 3 seconds) - Good for scalping
- `5`: Balanced (every 5 seconds) - Most common
- `10`: Slow (every 10 seconds) - Less API strain
- `30`: Very slow (every 30 seconds) - Lightweight

### Disable/Enable Indicators
In `config.json`, each indicator section has `"enabled": true/false`:

```json
"volume": {
  "enabled": true      // Set to false to disable volume alerts
},
"rsi": {
  "enabled": true      // Set to false to disable RSI alerts
},
```

### Turn Off Notifications/Sounds
```json
"general": {
  "enable_notifications": true,  // Set to false for quiet mode
  "enable_sound": true           // Set to false to mute
}
```

## Understanding the Log

When you see alerts in the log file:

```
[VOLUME] SOL/USDT - Volume Spike @ 141.2340
```
- **[VOLUME]** = Alert category
- **SOL/USDT** = Trading pair
- **Volume Spike** = Specific signal
- **@ 141.2340** = Price at alert time

---

## Alert Categories

| Symbol | Meaning |
|--------|---------|
| 🔴 [VOLUME] | Volume-based signals |
| 🔵 [CVD] | Cumulative Volume Delta |
| 🟣 [RSI] | RSI indicator |
| 🟠 [MACD] | MACD indicator |
| 🟡 [STOCH] | Stochastic indicator |

## Troubleshooting - Quick Fixes

| Problem | Solution |
|---------|----------|
| Python not found | Run setup_windows.bat again |
| No alerts | Check config.json - enable indicators |
| High CPU | Increase check_interval to 10-30 |
| No notifications | Check Windows notification settings |
| Can't connect to Binance | Check internet, wait 1 min, try again |

❌ Don't enable all indicators if not needed
